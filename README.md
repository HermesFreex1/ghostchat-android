# GhostChat 🎭

Anonymous P2P messaging app with themes, WebRTC calls, and voice messages.

## Features
- 🔒 Anonymous - No login, no phone, no email required
- 💬 P2P messaging via BroadcastChannel
- 📞 WebRTC voice & video calls
- 🎤 Voice messages
- 🫧 6 beautiful themes (Liquid Glass, Neon Cyber, Midnight Ocean, Aurora, Sunset, Matrix)
- 🛡️ E2E-style encryption badges
- ✅ Read receipts & typing indicators
- 🎨 Customizable accent colors & wallpapers
- 📱 Android APK via Capacitor

## Development

```bash
npm install
npm run dev
```

## Build Android APK

Push to GitHub and the workflow will automatically build the APK.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Capacitor (Android)
- Lucide React icons
